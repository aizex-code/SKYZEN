SKYZEN V16 — EXPLICIT PLAYBACK, TIMELINE COMPOSITING, CLEAN UI
============================================================

Playback behavior
-----------------
1. Selecting a media-bin video now loads it paused. Playback begins only after
   Play is pressed; Pause stops playback without implicit resume on selection.
2. FFmpeg composite layers now shift their source timestamps to each clip's
   project start before applying project-time enable intervals. Previously,
   clips starting after 0 seconds could be invisible in the merged preview.
3. Project snapshots use an existing, non-empty proxy only. If proxy creation
   has not completed, the original media path is used instead of a missing
   proxy path. This prevents intermittent preview render failures.
4. Preview cache profile was bumped so stale composites generated by the old
   timestamp behavior are not reused.

UI structure
------------
1. Main workspace construction moved to app/ui/editor_layout.py.
2. Theme styling remains in app/ui/theme.py.
3. Main-window code now focuses on editor state and panel integration while the
   separate UI package owns the layout. Existing left/player/timeline/inspector
   widgets and their signals are retained.

Validation
----------
Automated regression tests and Python compilation pass. FFmpeg composite smoke
tests are run separately where the local FFmpeg executable is available. Actual
Qt/Windows playback must be confirmed on the target machine because PySide6 is
not installed in this build environment.
