SKYZEN PATCH 05 CHANGELOG — AUDIO DROP STABILITY AND TRACK ORDER
Baseline: Skyzen V43 Stability Patch 04
Status: Automated tests and compilation pass; live Windows/PySide6 verification pending.

CHANGES
1. Normalized media kinds case-insensitively at the track/model boundary so Audio/audio cannot be misclassified as a video track.
2. Added audio-only insertion gaps directly below the Main lane. Overlay insertion gaps accept visual media only, preventing music from entering the overlay insertion workflow. The general top/bottom media drop targets still accept audio and route it to the audio stack below Main.
3. Corrected audio insertion-slot calculation to use the audio stack rather than a global displayed row index.
4. Positioned the first populated audio lane directly below the sticky Main lane and reserved viewport space for both rows to avoid overlap while scrolling. The shared row geometry is used by the timeline and layer headers.
5. Bounded audio waveform pixmap allocation and tiled the waveform across the clip, avoiding large pixmap allocations for long/high-zoom audio clips.
6. Added guarded drag/drop commits and diagnostic logging to logs/timeline_drop_errors.log where possible.
7. Added pure geometry regression tests for audio-lane placement and sticky behavior.
