SKYZEN PATCH 07 CHANGELOG — REAL TOOL LIBRARIES AND TYPED LAYERS
Baseline: user re-uploaded Skyzen V43 Stability Patch 05.
Purpose: replace the nonfunctional placeholder tool panels with real preset cards and shared timeline-layer integration while preserving existing Media/Audio paths.
Status: Python compilation, automated tests, and FFmpeg graph smoke renders pass. Windows/PySide6 GUI verification is pending.

CHANGES
1. Added app/left_toolbar/ with separate media_tool, audio_tool, text_tool, effect_tool, and adj_tool modules.
2. Rebuilt the left toolbar as compact Media / Audio / Text / Effects / Adjustments buttons, with a chevron overflow menu for narrow panels.
3. Added searchable, two-column preset libraries for Text, Effects, and Adjustments. Preset cards have visual previews and a + button over the thumbnail; cards also support drag-and-drop.
4. Added a dedicated application/x-skyzen-tool-asset drag payload and timeline drop routing for typed presets.
5. Added typed tool clips to the existing visual overlay track model. These clips retain timeline start/duration, selection, trimming, movement and undo-history behavior through the existing timeline infrastructure.
6. Added half-height typed rows and matching Text / Effects / Adjustments colors in timeline clip surfaces and layer headers.
7. Text presets render to transparent PNG assets. Inspector exposes text content, font size, and color; changing these regenerates the asset and refreshes the project preview.
8. Added effect rendering for Warm Film, Cool Night, Soft Glow, Vignette, VHS, and High Contrast, active only over the effect clip's half-open time range and applied to visual layers beneath the effect lane.
9. Added local adjustment scope (visual layers below) and whole-project scope. Whole-project grading runs after the full visual composite; supported properties include brightness, contrast, saturation, gamma, temperature and tint.
10. Added typed-tool render snapshot metadata and cache-signature fields so edits to typed layers invalidate stale preview composites.
11. Reused existing Media/Audio import pathways and rejected regular media drops onto typed tool lanes to avoid accidental type mixing.
12. Added typed tool-layer regression tests for catalog IDs, snapshot separation, effect filters, and project-grade filter generation.
