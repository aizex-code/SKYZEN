# Skyzen project footprint

This repository is the Skyzen community video-editor project. Its goal is to remain
free for non-commercial use and open to community improvements, while prohibiting
sales of the application, modified versions, and paid upgrades.

- Read `README.md` for setup and project overview.
- Read `LICENSE.md` for the full license.
- Read `CONTRIBUTING.md` before submitting changes.
- Read `PRIVACY.md` for data-handling scope.
- Historical patch notes document development iterations; see `docs/PROJECT_HISTORY.md`.

Each project directory contains a copy of the license and this footprint notice.
Third-party materials may have separate licenses.
