# Skyzen UI modules

- `editor_layout.py`: assembles the top bar, left media browser, central preview,
  right inspector, and bottom timeline with resizable splitters.
- `theme.py`: shared neutral-charcoal palette and cyan accent.
- `../main_window/main.py`: application startup, shortcuts, and panel wiring.

Keep layout/styling here; keep editing and playback behavior in their own modules.
