# Community Code of Conduct

We want Skyzen to be a welcoming place for people of different experience levels.

- Be respectful, constructive, and patient.
- Critique code and ideas, not people.
- Welcome beginner questions and explain technical feedback clearly.
- Do not harass, threaten, discriminate against, or expose private information about
  other people.
- Keep discussions focused on improving Skyzen and its community.
- Report abusive behavior to the repository maintainers rather than escalating it.

Maintainers may edit, remove, or decline contributions that violate these expectations.
