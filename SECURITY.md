# Security policy

Please do not publish credentials, private media, personal project files, or a working
exploit in a public issue.

For a security-sensitive report, contact the repository maintainers through a private
contact method configured on the official GitHub repository. If no private contact is
configured, open a minimal public issue that asks for a private reporting channel and
does not include exploit details.

Include the affected version/commit, impact, reproduction steps, and any mitigation
you know. Do not expect a response-time guarantee from this community project.
